## On Jeff's machine

This section is added by the jeff-mods `tstack` plugin.

- Start the replacement branch with `agent-git claim`, so it is
  `task/<id>-<slug>` from `origin/dev`.
- Taking over someone else's PR on a repository Jeff does not own means
  comments, closes, and replacement PRs there are external actions. Ask Jeff
  before each one.
- The replacement merges through `agent-git land` after Jeff approves the exact
  head, as the `full-send` skill's "On Jeff's machine" section describes.
