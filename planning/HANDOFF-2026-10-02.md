## How to work here

Read `AGENTS.md`. To develop a mod live, copy it into a session's dev-mods folder through the `plugin-authoring` skill,
or start `claude --plugin-dir plugins/<name>`. Do not leave a dev copy beside the installed one: a session that loads
both doubles every hook. Each plugin's `$.store` is keyed by where it loaded from, so a dev copy starts with an empty
store. After a change, commit, push, then `claude plugin marketplace update jeff-mods` and
`claude plugin update <name>@jeff-mods`.
